# Demo dataset УПП-100

Synthetic polystyrene plant for **software testing only**
(Package §67, Technical Spec §85–§86). Not for engineering
certification.

## Contents

- Seed label: `upp100-v1`
- ~61 equipment tags across the 10 Package §67 types
  (pumps, reactor, agitator, HEX, compressor, cooling, valve, tank,
  motor, instrumentation)
- Connected topology (spanning tree + typed links)
- Failure modes, distributions, maintenance, production impacts
- Versioned file: `scripts/seed/upp100/manifest.json`
